Usage: cellsim [OPTIONS]

A command-line tool for running molecular communication simulations.
Combine options to customize output format and settings.

Options:
  -b, --binary            Output the simulation result as a .bin file
  -c, --csv               Output the simulation result as a .csv file
  -h, --help              Show this help message (cannot be combined with other options)
  -i, --image             Output the simulation result as image files
  -o, --output DIR        Specify the output directory (default: ./result/)
  -p, --param NAME=VAL    Override specified parameter(s) (multiple allowed)
  -s, --setting FILE      Specify the configuration file to use (default: ./config.json)
  -v, --video             Output the simulation result as a video file
      --load-cell-csv     Load initial cell positions from a CSV file
      --no-clean-output   Do not empty the output directory before execution; keep existing contents
      --param-sweep EXPR  Execute simulations across a parameter range (multiple allowed) (e.g., cell.cells.0.cellCount=1000:2000:100)

Notes:
  - `-h, --help` must be used alone.
  - The output directory will be created automatically if it does not exist.
